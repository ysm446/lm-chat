# UI スタイルガイド

作成日時: 2026-08-11 18:39
更新日時: 2026-08-11 18:39

この文書は LM Chat の UI に関する唯一の基準です。色、タイポグラフィ、余白、部品、状態、モーションのルールをまとめます。
旧 `docs/design/rules/electron-design-rules.md`（Electron デザインルール）はこの文書に統合しました。

## この文書の使い方

- **UI に触れる変更（`src/renderer/**` の CSS / コンポーネント）を行うときは、必ずこの文書に従う。**
- 迷ったら「既存の同種の部品を探して、そのトークンと寸法をそのまま使う」を優先する。新しい見た目を発明しない。
- ここに書かれた値から外れる必要がある場合は、理由を作業報告に書く。恒久的なルールになるなら、この文書を更新してから実装する。
- 触っているファイル・範囲の中に「既知のズレ」（最後の節）があれば、ついでに寄せてよい。ただし無関係な箇所の一括整形はしない。
- 実装の正はあくまで `src/renderer/styles.css` の `:root`。トークンを増やすときは先に `:root` へ追加し、コンポーネント側で生の色を書かない。

## 基本方針

- 長時間使うデスクトップアプリとして、情報密度・視認性・疲れにくさを優先する。装飾より、操作対象の位置・サイズ・状態が即座に分かることを優先する。
- 主用途は執筆・長い会話の読み書き。**本文の可読性が UI の飾りより常に優先**される。
- OS ネイティブ寄りの控えめな質感。過度な角丸、強いグラデーション、大きな影は使わない。
- サイドバー・チャット・設定・一覧・モーダルは、同じ余白・フォント・区切りの感覚で統一する。
- hover / active / focus / disabled / loading / drag の状態を必ず設計する。
- ドラッグ・リサイズ・スクロールなど操作領域は、見た目より広く取る。
- テーマはダーク固定（`color-scheme: dark`）。ライトテーマは現状サポートしない。

## 1. 色

### 1.1 トークン一覧（`styles.css` の `:root`）

新しい色を使うときは、まずこの表のどれかで表現できないか検討する。

| トークン | 値 | 用途 |
|---|---|---|
| `--bg` | `#0d0f14` | アプリ最下層・中央ペイン・コードブロック背景 |
| `--bg-sidebar` | `#111318` | ModelBar / ActivityBar / 左右サイドバー / StatusBar / モーダル内ナビ |
| `--bg-chat` | `#13161e` | チャット面 |
| `--bg-input` | `#1a1d27` | 入力欄・トラック（バー）の地 |
| `--bg-card` | `#1c1f2b` | モーダル面・ユーザーバブル・カード |
| `--bg-elevated` | `#20233080` | 一段浮いた補助面（半透明） |
| `--border` | `#252830` | 通常の区切り線・パネル境界 |
| `--border-strong` | `#2e3140` | 入力枠・カード枠・スクロールバー thumb |
| `--text` | `#e2e4ef` | 本文・主要ラベル |
| `--text-dim` | `#9499b0` | 補助ラベル・非アクティブ・placeholder より濃い説明文 |
| `--text-faint` | `#5c6078` | メタ情報・placeholder・アイコンの既定色 |
| `--accent` | `#7c5af7` | 現在位置・主要アクション・focus |
| `--accent-hover` | `#6d4de6` | accent 背景ボタンの hover |
| `--accent-soft` | `rgba(124,90,247,0.12)` | 選択中・アクティブ行の背景 |
| `--accent-border` | `rgba(124,90,247,0.35)` | focus 枠・アクティブ枠 |
| `--danger` | `#ef4444` | 破壊的操作の主色 |
| `--danger-soft` | `rgba(239,68,68,0.12)` | 破壊的操作の hover 背景 |

### 1.2 使い分けのルール

- **テキストは 3 段階 + disabled**。本文 `--text` / 補助 `--text-dim` / メタ・placeholder `--text-faint`、disabled は `opacity: 0.5`（`0.4`〜`0.5`）と `cursor: not-allowed | default` をセットで指定する。色を薄くするだけの disabled にしない。
- **面の階層は背景差 + 1px の薄い border** で作る。強い線や影で区切らない。
- **hover は白のオーバーレイ**で表現し、次の 3 段階に統一する。

  | 用途 | 値 |
  |---|---|
  | 一覧行・ツリー行・セクションヘッダの hover | `rgba(255,255,255,0.04)` |
  | ボタン・アイコンボタンの hover | `rgba(255,255,255,0.07)` |
  | 押し込み・強い hover（アクティブ要素の hover 等） | `rgba(255,255,255,0.12)` |

- **アクセントは「現在位置」と「主要アクション」だけ**に使う。画面全体を紫で染めない。アクティブ状態は次の 3 点セットで表す。

  ```css
  .thing.active {
    background: var(--accent-soft);
    border-color: var(--accent-border);
    color: var(--accent);
  }
  .thing.active:hover { background: rgba(124, 90, 247, 0.18); }
  ```

- **破壊的操作**は色だけに頼らない。文言・配置・確認ダイアログで区別する。色を使う場合は文字 `#f87171`、hover 背景 `var(--danger-soft)`、枠 `var(--danger)` 系に寄せる。
- ダークテーマなので、純黒背景（`#000`）と純白本文は使わない。白は accent 背景上の文字（`color: #fff`）に限る。
- 状態色（成功・警告）を新設するときは `:root` にトークンを足してから使う。コンポーネント CSS に生の hex を散らさない。

## 2. タイポグラフィ

### 2.1 フォントファミリー

- UI フォントはユーザー設定（`--app-font-family`、`src/renderer/fontOptions.ts`）に従う。**コンポーネント側で `font-family` を直書きしない。**
- 例外は等幅のみ。コード・パス・モデル名・ログ・数値 ID は `"Cascadia Code", "Fira Code", "Consolas", monospace`。
- 数値が並ぶ表示（トークン数、速度、メーター値）は `font-variant-numeric: tabular-nums` を付けて桁を揃える。

### 2.2 サイズ階段

ルートは `font-size: 14px` / `line-height: 1.6`。以下の階段から選ぶ。

| サイズ | 用途 |
|---|---|
| `10px` | `.eyebrow`（大文字・`letter-spacing: 0.1em`）、スライダー端ラベル |
| `11px` | メタ情報、StatusBar、pill、tooltip、ヒント文 |
| `12px` | 補助ラベル、設定の説明、インラインコード、小さめボタン |
| `13px` | **UI の既定**。一覧行、ボタン、メニュー項目、設定ラベル、`.muted` |
| `14px` | ルート既定。チャット本文 |
| `16px` / `20px` | 見出し（多用しない） |

- `10px` 未満は使わない。
- 新規コードで `11.5px` / `12.5px` / `13.5px` のような半端値や `rem` を増やさない（既存の残りは「既知のズレ」）。
- 行間は UI ラベル `1.35`〜`1.45`、本文・チャット・エディタ `1.6`〜`1.65`。ツールバー内の一行テキストは固定高で中央揃えにする。
- 太さは `500`（強調ラベル）/ `600`（見出し・アクティブ）/ `700`（カード見出し）に留める。

## 3. 余白と密度

- 基本単位は **2 / 4 / 6 / 8 / 10 / 12 / 16 / 24 px**。この階段以外を新規に使わない。
- `gap` の既定は `8px`。密なツールバー・行内は `4px` / `6px`、セクション内のまとまりは `12px` / `16px`。
- 代表的な padding:

  | 対象 | padding |
  |---|---|
  | 一覧行・ツリー行 | `3px 6px` |
  | 小さなボタン・pill | `4px 8px` / `4px 10px` |
  | 通常ボタン | `6px 10px` / `6px 12px` |
  | 主要ボタン | `8px 16px` |
  | 入力欄 | `7px 10px` / `9px 12px` |
  | パネル・設定セクション | `12px 16px` / `16px` |
  | チャット面 | `24px 24px 120px`（下は入力欄ぶんの逃げ） |
  | チャットバブル | `12px 16px` |

- ランディングページ的な広い余白は使わない。情報量が多い画面は余白より alignment とグルーピングで整理する。

## 4. 角丸・境界・影・重なり

### 4.1 角丸

トークンだけを使う。生の px を新規に書かない。

| トークン | 値 | 用途 |
|---|---|---|
| `--r-sm` | `6px` | **既定**。ボタン、入力欄、一覧行、メニュー項目、コードブロック |
| `--r-md` | `10px` | アイコンボタン、コンテキストメニュー、tooltip |
| `--r-lg` | `14px` | モーダル、チャットバブル |
| `--r-xl` | `18px` | 大きな空状態カード |

- ピル・進捗バーは `999px`、円形（スライダー thumb、スピナー、ドット）は `50%`。
- チャットバブルは発話側の角だけ落とす（user は `border-bottom-right-radius: var(--r-sm)`、assistant は左下）。

### 4.2 境界と影

- 常設のパネル・サイドバー・分割ペインは **border と背景差** で区切る。影は使わない。
- 影は浮いた要素だけに使い、次の 3 種類に統一する。

  | 対象 | box-shadow |
  |---|---|
  | モーダル | `0 24px 64px rgba(0,0,0,0.6)` |
  | コンテキストメニュー・ポップオーバー | `0 16px 40px rgba(0,0,0,0.5)` |
  | tooltip | `0 6px 20px rgba(0,0,0,0.5)` |

### 4.3 z-index の帯

| 帯 | 用途 |
|---|---|
| `0`–`9` | ペイン内の重なり（進捗バー、ゴーストテキスト層など） |
| `10`–`29` | リサイズハンドル、固定ヘッダ、スティッキー要素 |
| `50`–`100` | ペイン内に浮く補助 UI（検索バー、インライン候補） |
| `1000` | モーダル backdrop、tooltip |
| `1100` | モーダル内で更に上に出す要素 |
| `2000` | コンテキストメニュー（常に最前面） |

新しい値は帯の中から選ぶ。帯を増やさない。

## 5. モーション

- transition は速度を 4 段階に統一する。

  | 速度 | 用途 |
  |---|---|
  | `0.1s` | 一覧行・メニュー項目など即応が要る hover |
  | `0.15s` | **既定**。background / color / border-color |
  | `0.2s ease` | 表示切替（opacity）、chevron の回転 |
  | `0.35s`–`0.4s ease` | メーター・進捗バーの幅 |

- `transition: all` は使わない。変化させるプロパティを列挙する。
- ローディングは既存パターンを使う（`.model-spinner` の回転、`.model-bar-progress` の波、`.typing-cursor` の点滅）。新しいアニメーションを増やさない。
- レイアウトが動く演出（要素の飛び込み、大きなスライド）は使わない。

## 6. 部品

### 6.1 ボタン

- **主要アクション**: `.primary-button`（`--accent` 背景 / `#fff` 文字 / `--r-sm` / `8px 16px` / `13px` / `weight 500`）。hover は `--accent-hover`。小型は `.primary-button.small`（`6px 12px`）。1 画面に主要ボタンは 1 つが原則。
- **二次アクション**: 背景 `rgba(255,255,255,0.04)` + `1px solid var(--border-strong)` + `--r-sm`。hover で背景を `0.07` に上げ、必要なら `border-color: var(--accent-border)`。
- **アイコンボタン**: 正方形。用途ごとに 4 サイズを使い分ける。

  | サイズ | 用途 | 角丸 |
  |---|---|---|
  | `26px` | メッセージアクション、インライン編集の確定/取消 | `--r-sm` |
  | `28px` | 行の「…」メニュー、ModelBar のイジェクト | `--r-sm` / `--r-md` |
  | `30px` | ModelBar のパネルトグル | `--r-md` |
  | `36px` | ActivityBar | `--r-md` |

  既定色は `--text-faint`、hover で `rgba(255,255,255,0.07)` + `--text-dim`（または `--text`）、アクティブは `--accent`。
- 危険操作のアイコンボタンは `.danger` 修飾で hover 時のみ赤系にする。既定状態から赤くしない。
- `:disabled` は `opacity: 0.4`〜`0.5` + `cursor: not-allowed | default` + hover 無効化をセットで書く。

### 6.2 入力欄

- 一行 input: 背景 `--bg-input`、枠 `1px solid var(--border-strong)`、`--r-sm`、padding `7px 10px`〜`9px 12px`。
- focus: `border-color: var(--accent-border)`。`outline: none` を書いたら、**必ず** border か box-shadow で focus を可視化する。focus が見えない入力欄を作らない。
- placeholder は `--text-faint`。本文と区別できる濃さを保つ。
- textarea は本文フォントと行間を優先し、上下 padding を十分に取る。高さが伸びる入力は最大高とスクロール挙動を決め、レイアウトジャンプを防ぐ。
- インライン編集の入力は `border-color: var(--accent-border)` を初期状態から付け、編集中であることを示す。

### 6.3 スライダー

- track は `height: 4px` / `border-radius: 2px` / 背景 `--border-strong`。
- thumb は `11px` の円、既定 `--text-dim`、hover で `--text` + `transform: scale(1.2)`、focus と `.active` で `--accent`。
- 既定値から変更されている状態は `.active` で accent を出して分かるようにする。
- 端の目盛りラベルは `10px` / `--text-faint`。
- 厳密な調整が要る設定では、スライダー単独にせず現在値表示（と必要なら数値入力・リセット）を併置する。
- ヒットエリアは縦 `24px` 以上を確保する（現状未達。「既知のズレ」参照）。

### 6.4 リストとツリー（サイドバー）

- 行の実効高は `26px`〜`32px`。padding `3px 6px`、左右 margin `4px`、角丸 `--r-sm`。
- hover は `rgba(255,255,255,0.04)`、選択中は `background: var(--accent-soft)` + 名前を `--accent`。
- タイトルは 1 行省略（`white-space: nowrap; overflow: hidden; text-overflow: ellipsis`）。全文は tooltip か詳細ペインで見せる。
- 副次情報（説明・日時）は `11px` / `--text-faint` で名前の下に置く。
- 行の操作ボタンは hover で出してよい（`opacity` を `0.2s` で遷移）。ただし削除・改名・移動などの重要操作は「…」メニューに常に置き、位置とメニュー構造を全画面でそろえる。
- ドラッグ可能な行には、ドラッグ中（`opacity: 0.4`）、ドロップ先（`outline: 1px solid var(--accent)` + `--accent-soft`）、禁止状態を用意する。

### 6.5 コンテキストメニュー

- `position: fixed` / `z-index: 2000` / `min-width: 160px` / `padding: 4px` / 背景 `#1e2130` / 枠 `--border-strong` / `--r-md` / 影は 4.2 の値。
- 項目は `padding: 9px 12px` / `13px` / `--r-sm`、hover `rgba(255,255,255,0.06)`。
- 破壊的項目は `.danger`（文字 `#f87171`、hover 背景 `--danger-soft`）で、メニューの最後に置く。

### 6.6 モーダルとポップオーバー

- モーダルは破壊的操作・重要設定・複雑な選択に限定する。軽い選択や補助操作は popover / メニュー / インラインパネルにする。
- backdrop は `rgba(0,0,0,0.55)` / `z-index: 1000`。面は `--bg-card` + `--border-strong` + `--r-lg` + モーダル影。
- 幅は内容に合わせる。選択系 `640px`、設定フォーム `760px` 程度を基本とし、`max-width: calc(100vw - 48px)` を必ず付ける。
- Escape で閉じる、backdrop クリックで閉じる、確定/取消の並びは全モーダルで同じにする。破壊的確認だけは backdrop クリックで閉じない選択もあり得るが、その場合は明示的に取消ボタンを置く。
- tooltip は `position: fixed` / `max-width: 240px` / `11px` / `line-height: 1.65` / `pointer-events: none` / `--r-md`。

### 6.7 チャット本文

- `.message-card` の `max-width` は `82%`（assistant は全幅）。本文が横に伸びすぎないようにする。
- user は `--bg-card` + `--border` のバブル、assistant は**背景なしの地の文**、system は amber 系の細い注記。この 3 者の描き分けを崩さない。
- Markdown 要素は本文より少しだけ階層差を出す。コードブロックは `--bg` 背景 + `--border-strong` 枠 + `--r-sm`、インラインコードは白 7% 背景 + `--border` + `4px` 角丸。
- 引用は `border-left: 3px solid var(--accent)` + `--text-dim`。表は `--border-strong` の罫線、ヘッダは白 4% 背景。
- 編集中の textarea は元の本文位置・サイズに近い見た目にして、編集モードに入ったことが自然に分かるようにする。
- 検索ハイライトは現在マッチをオレンジ、その他を黄色で区別する（`.search-highlight.current` / `.search-highlight`）。

### 6.8 バッジ・pill・チップ

- `.pill`: `padding: 4px 10px` / `border-radius: 99px` / `11px` / 背景 白 4% / 枠 `--border-strong` / 文字 `--text-dim`。
- トグルとして使う場合（`.pill-toggle`）、アクティブは 1.2 のアクセント 3 点セット。
- 状態を pill の色だけで伝えない。ラベル文言を必ず入れる。

### 6.9 スクロールバー

- 全域で共通（`width: 6px`、track 透明、thumb `--border-strong` → hover `--text-faint`、`border-radius: 99px`）。
- 個別領域でスクロールバーの太さ・色を上書きしない。

### 6.10 分割ペインとリサイズハンドル

- 見た目は `1px`（`--border`）。hover で `--accent`。
- ヒットエリアは `10px` 前後を `::after` で確保する。**ただし拡張は右方向のみ**（`inset: 0 -9px 0 0`）。左に伸ばすと左ペインのスクロールバーに重なってドラッグを奪うため。
- `cursor: col-resize`。ドラッグ中はテキスト選択を抑制する。
- サイドバーの幅は最小・標準・最大を決める（左 `220px` 前後を標準、右 `280px` 前後を標準）。折りたたみ時はカラム幅を `0px` にし、`display: none` にしない（グリッドのアイテム数が変わるため）。復帰導線として ActivityBar / ModelBar のトグルを必ず残す。

### 6.11 アイコン

- インライン SVG を直接書く（アイコンライブラリは導入しない）。
- 形式は `viewBox="0 0 24 24"`（または `0 0 20 20`）、`fill="none"`、`stroke="currentColor"`、`strokeWidth` `1.6`〜`2`、`strokeLinecap`/`strokeLinejoin` は `round`。
- 表示サイズは `12` / `14` / `16` を基本とし、目立たせたい場所だけ `18`。それ以外のサイズを増やさない。
- 色は必ず `currentColor`。親の `color` で状態を制御する。
- 意味が一般的な形を使い、独自アイコンを増やしすぎない。

### 6.12 空状態・ローディング

- 空状態は `.empty-card`（`--bg-sidebar` + `--border-strong` + `--r-xl` + `padding: 40px 36px`）を基本形にする。見出し `20px/700`、説明 `.muted`、次の行動につながるボタンを 1 つ置く。
- 読み込み中は既存のスピナー・進捗バーを使い、レイアウトが飛ばないように領域を確保しておく。

## 7. 状態設計

すべての操作可能要素について、次を設計する。抜けがあれば実装前に決める。

| 状態 | 表現 |
|---|---|
| hover | 白オーバーレイ（1.2 の 3 段階） |
| active / 選択中 | アクセント 3 点セット |
| focus | `--accent-border` の枠。`outline: none` にしたら代替を必ず用意 |
| disabled | `opacity: 0.4`–`0.5` + `cursor` + hover 無効化 |
| loading | 既存スピナー / 進捗バー。操作は無効化する |
| drag / drop | ドラッグ元 `opacity: 0.4`、ドロップ先 `outline: 1px solid var(--accent)` + `--accent-soft` |

## 8. アクセシビリティ

- キーボードだけで主要操作ができるようにする。focus visible を消さない。
- アイコン単体ボタンには `aria-label`（または `title`）を必ず付ける。
- 色だけで状態を伝えない。文言・アイコン・位置を併用する。
- クリック可能領域は最低 `24px`、頻繁に押す操作は `28px` 以上。
- テキストは disabled でも読める程度のコントラストを保つ。

## 9. 既知のズレ

以下は現状の実装に残っている逸脱。**新規コードで真似しない。** 該当箇所を触ったときに寄せる。

- `--user-bubble` / `--user-bubble-hover` / `--user-bubble-border` は定義のみで未使用。ユーザーバブルは実際には `--bg-card` を使っている。
- `--bg-card-hover: #21253200` はアルファ `00`（完全透明）で、事実上使われていない。
- フォントサイズに `11.5px` / `12.5px` / `13.5px` / `9px` / `rem` 指定が残っている。
- `border-radius` の生 px（`4px` / `5px` / `8px` / `12px` など）がトークンと混在している。
- 破壊的操作の色が `#f87171` / `#ff6060` / `rgba(255,80,80,*)` / `--danger` に分散している。
- アイコンボタンの `aria-label` がほとんど付いていない。
- `.settings-slider` のヒットエリアが track と同じ `4px` しかなく、6.3 の「縦 24px 以上」を満たしていない。
- 一部のコンテキストメニュー・tooltip の背景が生 hex（`#1e2130` / `#202330`）でトークン化されていない。
