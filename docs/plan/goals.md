# Goals

作成日時: 2026-06-07 21:51
更新日時: 2026-06-21

このファイルは、LM Chat の方向性と判断基準を共有するための進捗管理ドキュメントです。

## 長期ゴール

- ローカル LLM と安全に対話しながら、作品制作、調査、思考整理を継続できる個人用チャット環境にする。
- ワークスペース単位で記憶、資料、会話、モデル設定を扱い、文脈が混ざらないようにする。
- 長いプロジェクトでは、全文投入ではなく要約、資料検索、記憶検索を組み合わせて扱えるようにする。

## 中期ゴール

- ワークスペース単位のエクスポート / インポートを安定運用できるようにする。
- 小説や長期制作向けに、章単位の要約と作品全体レビューの流れを設計する。
- Documents と memory の検索品質、注入量、UI 操作を調整しやすくする。

## 判断基準

- 既存のチャット体験を壊さず、ワークスペースごとの文脈管理を強くする。
- 重い処理や長大コンテキストに頼りすぎず、保存済み要約や検索で再利用できる形にする。
- 重要なデータ操作は、全体データとワークスペース単位を明確に分ける。
